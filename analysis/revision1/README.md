# Revision-1 analyses

Scripts and outputs added in the first revision of the paper. See the main
README (section "Revision-1 analyses") for what each script computes and which
section of the paper it supports. All scripts are run from this directory and
read the raw data from `../../data/` and `../../data/supplementary/`.

Outputs kept in this directory: `tab_p3_delaunay.csv` (Delaunay coverage),
`tab_p4_robustnost.csv` (tercile robustness), `tab_p7_sum.csv` (noise
experiment).
