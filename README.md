# VTL Localization Optimizations — Simulator, Data and Analysis

Source code, raw simulation data and analysis scripts accompanying the paper:

> *Local Voronoi Computation and Sweep Line Intersection for Efficient Voronoi-Based Grouping Test Localization in Wireless Sensor Networks.* Submitted to *Sensors* (MDPI), 2026.

The paper proposes and evaluates two optimizations of the Voronoi diagram-based
grouping test localization (VTL) scheme (Li et al., *Electronics* **2022**, *11*,
2961, [doi:10.3390/electronics11182961](https://doi.org/10.3390/electronics11182961)):

1. **Local Voronoi computation** — the Voronoi diagram of a group is built from
   only the anchor node with the strongest RSSI and its *k* nearest neighbours,
   instead of all anchor nodes of the group.
2. **Sweep line intersection** — an exact sweep line algorithm replaces the
   brute-force grid scan when intersecting the positive regions.

## Repository layout

```
simulator/   PyQt6 GUI simulator of the VTL algorithm and both optimizations
analysis/    Scripts that reproduce all tables and figures of the paper
data/        Raw results of all 5184 simulation runs (8 CSV files + data dictionary)
figures/     Figures generated by the analysis scripts (PNG 600 dpi + PDF)
```

## Installation

Python 3.11+ is required.

```
pip install -r requirements.txt
```

The pinned versions in `requirements.txt` (NumPy 2.4.2, SciPy 1.17.0,
pandas 3.0.0, Matplotlib 3.10.8) are the exact versions used to produce all
numbers and figures in the paper. The additional GUI dependencies (PyQt6,
pyqtgraph, Shapely, foronoi) are needed only for running the simulator itself.

## Reproducing the paper's tables and figures

All results in the paper are computed from `data/*.csv` by the scripts in
`analysis/` (run them from inside the `analysis/` directory; total runtime is
a few minutes on a desktop machine):

```
cd analysis
python analiza.py             # statistics -> tab_*.csv + rezultati.md
python slike.py               # data figures  -> ../figures/fig1..fig5 (PNG+PDF)
python slike_ilustracije.py   # illustrations -> ../figures/ill_*      (PNG+PDF)
```

`analiza.py` performs the full analysis: descriptive statistics per
configuration; the three experiments (local vs. global Voronoi, sweep line vs.
grid scan, combined optimizations); paired two-sided Wilcoxon signed-rank tests
over the 144 (network size, repetition) pairs per area with Holm correction and
Cohen's dz effect sizes; and the simulator validation (Spearman correlations of
E_a and P_e with network density).

## Running the simulator

```
cd simulator
python simulator.py
```

The GUI allows setting all parameters (area size, number of nodes, anchor
percentage, communication radius, number of groups K, grid cell size, Voronoi
mode global/local, neighbourhood size k, intersection algorithm grid scan/sweep
line, seed), visualizes the network and the localization process, measures the
execution time of each algorithm phase, supports batch runs, and exports
results to CSV. The dataset in `data/` was produced with seed 4275; see
`data/README.md` for the complete run matrix and data dictionary.

## Data

The `data/` directory contains the raw results of all 5184 simulation runs,
with a complete data dictionary in [`data/README.md`](data/README.md). The
execution times were measured on a single desktop machine (Windows 11, CPython);
relative comparisons between configurations are the meaningful quantities.
