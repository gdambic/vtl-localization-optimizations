# VTL Localization Optimizations — Simulator, Data and Analysis

Source code, raw simulation data and analysis scripts accompanying the paper:

> *Local Voronoi Computation and Sweep Line Intersection for Efficient Voronoi-Based Grouping Test Localization in Wireless Sensor Networks.* Submitted to *Sensors* (MDPI), 2026.

The paper proposes and evaluates two optimizations of the Voronoi diagram-based
grouping test localization (VTL) scheme (Li et al., *Electronics* **2022**, *11*,
2961, [doi:10.3390/electronics11182961](https://doi.org/10.3390/electronics11182961)):

1. **Local Voronoi computation** — the Voronoi diagram of a group is built from
   only the *k* anchor nodes nearest to the strongest-RSSI anchor (including
   that anchor itself), instead of all anchor nodes of the group.
2. **Sweep line intersection** — an exact sweep line algorithm replaces the
   brute-force grid scan when intersecting the positive regions.

## Repository layout

```
simulator/   PyQt6 GUI simulator of the VTL algorithm and both optimizations,
             plus a headless batch runner (headless_batch.py)
analysis/    Scripts that reproduce all tables and figures of the paper
data/        Raw results of all 5184 primary simulation runs (8 CSV files
             + data dictionary); data/supplementary/ holds the 464
             supplementary runs added in revisions
figures/     Figures generated by the analysis scripts (PNG 600 dpi + PDF)
```

## Installation

Python 3.11+ is required.

```
pip install -r requirements.txt
```

The pinned versions in `requirements.txt` (CPython 3.13.2 with NumPy 2.5.2,
SciPy 1.18.1, pandas 3.0.5, Matplotlib 3.11.1, Shapely 2.1.2, foronoi 1.0.3)
are the versions used for all simulations and analyses reported in the paper
(Section 2.2). All reported numbers reproduce exactly under these versions;
the only known numerical deviation vs. earlier SciPy releases is in
Shapiro-Wilk p-values at the 8th significant digit, which are not reported in
the paper and affect no decision. The GUI dependencies (PyQt6, pyqtgraph) are
needed only for running the simulator itself.

## Reproducing the paper's tables and figures

All results in the paper are computed from `data/*.csv` by the scripts in
`analysis/` (run them from inside the `analysis/` directory; total runtime is
a few minutes on a desktop machine):

```
cd analysis
python analiza.py             # statistics -> tab_*.csv + rezultati.md
python slike.py               # data figures  -> ../figures/fig1..fig5 (PNG+PDF)
python slike_ilustracije.py   # illustrations -> ../figures/ill_*      (PNG+PDF)
```

`analiza.py` performs the full analysis: descriptive statistics per
configuration; the three experiments (local vs. global Voronoi, sweep line vs.
grid scan, combined optimizations); paired two-sided Wilcoxon signed-rank tests
over the 144 (network size, repetition) pairs per area with Holm correction and
Cohen's dz effect sizes; and the simulator validation (Spearman correlations of
E_a and P_e with network density).

## Supplementary experiments (revision)

Four sets of supplementary experiments (464 runs in total, reported in
Sections 3.1 and 3.6 of the paper) were added in revisions:

1. **Quantitative validation** (`sim_a1.csv`, `sim_a2.csv`) — the baseline
   configuration at the operating point of Li et al. (100 m × 100 m, 140 nodes
   / 40 anchors) and across anchor ratios of 10–70%, five seeds each.
2. **Anchor-density sensitivity** (`sim_b.csv`) — the combined optimizations
   (*k* ∈ {8, 10, 12, 16}) vs. the original algorithm at anchor ratios of 20%
   and 60% (200 m × 200 m, 100–900 nodes, three seeds; Table 5).
3. **Seed stability** (`sim_c.csv`) — the original and combined configuration
   (*k* = 10, 12) with ten independent seeds at 200, 600 and 1000 nodes
   (Table 6).
4. **RSSI shadowing noise** (`sim_d.csv`, `sim_d_li.csv`) — log-normal
   shadowing applied to the strongest-anchor selection (path-loss exponent
   η = 3, σ ∈ {4, 8} dB), at N ∈ {200, 600, 1000} (three seeds) and at the
   operating point of Li et al. (five seeds); produced by
   `simulator/headless_batch_noise.py` (σ = 0 baselines reuse `sim_c.csv` /
   `sim_a1.csv`). `sim_d_sanity.csv` verifies that σ = 0 reproduces the
   noise-free results bit-for-bit.

The raw runs live in `data/supplementary/` together with per-configuration
summaries (`summary_*.csv`) and the statistical outputs (`tab_dorada_*.csv`,
i.e. Tables 5–6 and the validation numbers). `sim_0_sanity.csv` and
`sim_d_sanity.csv` are determinism checks of the batch runners, not part of
the 464.

To re-run the simulations, execute `simulator/headless_batch.py` (Qt runs
offscreen, results are appended to the output CSV and already-computed rows
are skipped on restart), e.g. for the determinism check and the sensitivity
campaign:

```
cd simulator
python headless_batch.py --out sim_0_sanity.csv --area 200 --sizes 200 \
    --seeds 4275 --anchor-ratio 40 --configs grid-global,sweep-local:12
python headless_batch.py --out sim_b.csv --area 200 --sizes 100:900:100 \
    --seeds 4275,1001,1002 --anchor-ratio 20 \
    --configs grid-global,sweep-local:8,sweep-local:10,sweep-local:12,sweep-local:16
```

(The validation runs use `--area 100 --sizes 140 --anchor-ratio 28` and
`--sizes 100` with `--anchor-ratio 10..70`; the seed-stability runs use
`--sizes 200,600,1000 --seeds 4275,2001..2009 --anchor-ratio 40
--configs grid-global,sweep-local:10,sweep-local:12`.)

To reproduce the summaries and the statistics from the raw CSVs (both scripts
operate on the CSVs in the current directory):

```
cd data/supplementary
python ../../analysis/summary.py         # -> summary_*.csv
python ../../analysis/analiza_dorada.py  # -> tab_dorada_*.csv + rezultati_dorada.md
```

## Running the simulator

```
cd simulator
python simulator.py
```

The GUI allows setting all parameters (area size, number of nodes, anchor
percentage, communication radius, number of groups K, grid cell size, Voronoi
mode global/local, neighbourhood size k, intersection algorithm grid scan/sweep
line, seed), visualizes the network and the localization process, measures the
execution time of each algorithm phase, supports batch runs, and exports
results to CSV. The dataset in `data/` was produced with seed 4275; see
`data/README.md` for the complete run matrix and data dictionary.

## Data

The `data/` directory contains the raw results of all 5184 primary simulation
runs, with a complete data dictionary in [`data/README.md`](data/README.md);
`data/supplementary/` adds the 464 supplementary runs (same column layout,
plus `WallClock_s` and `Timestamp`, produced by `simulator/headless_batch.py`). The
execution times were measured on a single desktop machine (Windows 11, CPython);
relative comparisons between configurations are the meaningful quantities.
